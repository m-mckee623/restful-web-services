Den Haag Preschools — Research Map

Childcare quality, price and international/bilingual programmes. Diversity figures are an optional, separate research layer — see the info panel.

About this map

Purpose: this is a research/reporting tool. It maps childcare quality (star rating and number of reviews) for preschools in Den Haag, and separately, as an opt-in layer, an aggregate neighbourhood-level diversity statistic intended for studying segregation trends in childcare, not for choosing a school by ethnic composition.

Data: the locations, ratings, prices and diversity figures currently loaded are illustrative sample data, not real institutions or real prices. For a production version, source real locations from the official LRK (Landelijk Register Kinderopvang), and aggregate statistics from Gemeente Den Haag open data or CBS StatLine. Never source or publish per-child ethnicity data; only use officially published, aggregated, school- or neighbourhood-level figures.

Price: shown as an indicative hourly rate in EUR. Real childcare in the Netherlands is usually reimbursed substantially by kinderopvangtoeslag (the government childcare benefit) for eligible families, so the effective cost is often well below the sticker rate — eligibility can depend on residency/work status, worth checking directly for international families.

International/bilingual programme: a badge shown when a location offers English (or another non-Dutch) medium of instruction or an international curriculum. This is a normal school-choice factor, kept separate from the diversity research layer below.

Distance: shown from a fixed reference point on Laan van Meerdervoort, for orientation only — proximity is not used to rank or filter results.

Responsible use: the diversity layer is deliberately not combined into any "best school" ranking and cannot be used to sort or filter results. Please don't repurpose this data to steer enrolment decisions by ethnic composition.
